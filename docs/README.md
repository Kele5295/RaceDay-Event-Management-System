# RaceDay Part 1 Documentation

This folder contains the planning and database documentation for the RaceDay Event Management System.

## Files

### RaceDay_ERD.pdf
Contains the Entity Relationship Diagram for the RaceDay database, including entities, attributes, primary keys, foreign keys, relationships and cardinalities.

### RaceDay_API_Endpoint_Plan.md
Contains the planned RESTful API endpoints for authentication, profiles, events, event types, categories, enrolments and results.

### RaceDay_Database.sql
Contains the Microsoft SQL Server database creation script, constraints, sample data and verification queries.

### ci-success.png
Provides evidence that the GitHub Actions Part 1 validation workflow completed successfully.

## Purpose

These documents form the planning foundation for the RaceDay implementation that will continue in Part 2.
